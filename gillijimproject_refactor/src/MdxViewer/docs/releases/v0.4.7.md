## parp-tools WoW Viewer v0.4.7

.NET 10 / OpenGL 3.3 world viewer and debugging surface for WoW data from Alpha `0.5.3` through `4.0.0.11927`.

### Changes since v0.4.6.1

- Performance work now removes more avoidable world-scene cost: streamed ADT terrain is back on a tile-batched submission path, world-object visibility broad-phases streamed chunk buckets before per-instance admission, and tighter near-field or WDL handoff or object-streaming policies reduce far-scene churn.
- UI workflow is now fixed-shell-first again: the active viewer starts with static left and right sidebars, dock panels are opt-in, and the right sidebar now uses stacked sequential sections instead of the broken tab host and failed bottom-drawer detour.
- PM4 object suggestions no longer rank against the whole loaded scene with a WMO-biased heuristic first; the active matcher is now local-first and geometry-first, which is the concrete fix for the recent OilPlatform collapse.
- Under the hood, more world-runtime ownership keeps moving into `wow-viewer` libraries, especially around shared visibility and pass-planning seams, while `MdxViewer` stays the active compatibility host.

### Quick start

1. Extract the ZIP for your platform.
2. Run `ParpToolsWoWViewer`.
3. In-app, use `File > Open Game Folder (MPQ)` and select your client path.
4. Pick the client build in the build-selection dialog.
5. Load worlds from the left sidebar and use the right sidebar sections for `Inspect`, `Terrain`, `PM4`, `World`, and `Diagnostics`.
