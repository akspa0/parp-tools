1. Input Contract

V7.4 consumes visual cues, terrain priors, and explicit occlusion or editing context. The important architectural change is that WDL is not just decorative context; it is the coarse terrain scaffold the model is increasingly expected to conform to.

Channels 1-3

Minimap RGB

Primary visible surface evidence.

Channels 4-6

Normal Map RGB

Slope and orientation cues.

Channel 7

WDL Height Prior

17x17 coarse height lattice resized into the same normalized global range as the terrain target.

Channels 8-9

Height Min / Max Hints

Per-tile range hints for absolute terrain scale.

Channels 10-11

Liquid Mask / Liquid Height

Water coverage and supporting elevation prior.

Channel 12

Object Footprint Mask

Regions where minimap pixels are known to be terrain-poor or overwritten.

Channel 13

Brush Mask

Patch-scale editing archaeology distilled into a tile mask.

2. Generator

The generator is still a 5-level U-Net, but the active code path now uses reflect padding and supports a WDL-trestle global head. New runs are meant to refine the global surface over WDL instead of hallucinating the entire absolute surface from scratch.

flowchart TD A[13-channel input] --> B[Encoder 64] B --> C[Encoder 128] C --> D[Encoder 256] D --> E[Encoder 512] E --> F[Encoder 1024] F --> G[Bottleneck 2048] G --> H[Bounds head x4] G --> I[Decoder 1024] I --> J[Decoder 512] J --> K[Decoder 256] K --> L[Decoder 128] L --> M[Decoder 64] M --> N[Raw 2-channel output] A --> O[WDL channel] O --> P[Global trestle path] N --> Q[Global delta via tanh] Q --> R[Clamp WDL plus scaled delta] N --> S[Local detail channel] R --> T[Final global channel] S --> U[Final local channel]
  • Encoder and discriminator convolutions use padding_mode="reflect" in the active code path to avoid the artificial void introduced by zero padding.
  • The global channel can operate as WDL + learned residual rather than absolute terrain-only prediction.
  • The local channel remains a bounded detail surface for within-tile structure.
  • The bounds head still predicts tile/global range hints.

3. Discriminator

PatchGAN remains lightweight, but the schedule and stabilization controls are now part of the architecture story because they materially affect what the model learns late in training.

flowchart LR A[Predicted or real 2-channel height] --> B[PatchGAN 64] B --> C[PatchGAN 128] C --> D[PatchGAN 256] D --> E[PatchGAN 512] E --> F[Patch map]
  • Real/fake target smoothing, label noise, input noise, and discriminator gradient clipping are active controls.
  • Best-triggered GAN bursts remain the preferred schedule strategy.

4. Loss Stack

The current objective is explicitly sharper and more stitch-aware than the earlier V7.x path.

Base

Global / Local / Bounds

Primary terrain reconstruction terms.

Sharpness

Gradient / Edge / Laplacian / Frequency / SSIM

First and second derivative plus frequency-domain pressure.

New

Transition Loss

Upweights target regions with strong terrain changes so hard breaks stop collapsing into ramps.

New

Tile-Edge Loss

Upweights the outer border band so tiles learn to stay stitchable in a quilt.

Adversarial

Best-Triggered GAN

GAN pressure comes in short bursts after validation improvements.

5. Validation And Preview Loop

Validation is an active control surface, not passive reporting.

flowchart TD A[Train epoch] --> B[Validation pass] B --> C{Valid best?} C -->|yes| D[Write best.pt] D --> E[Arm GAN burst] C -->|no| F[Patience increments] B --> G[ReduceLROnPlateau] B --> H[Write preview PNGs and JSON] H --> I[Static sentinel tiles plus random held-out tiles]
  • Mixed previews include fixed high-signal tiles and random held-out tiles each epoch.
  • Context sheets explicitly show object mask, liquid mask, and brush mask inputs.
  • The practical cap is now 100 epochs because the best validated run peaked at epoch 51 and was finished by early stop at epoch 112.

6. Compatibility And Proof Boundary

The new code path is stronger, but proof levels differ.

  • Old checkpoints can still load under legacy semantics through checkpoint metadata.
  • New runs are intended to use the wdl-trestle-reflect-v1 variant.
  • Inference currently also includes an edge-anchor safety rail to WDL for exported development-map tiles.
  • The new architecture changes are code-complete, but retrained-model proof still requires a fresh run from the best epoch-51 checkpoint or a new run under the improved variant.
