1. Input Channels — What the Model Sees

Each tile becomes a 12-channel 512×512 tensor. RGB appearance, surface orientation, coarse world priors, and occlusion hints give the model enough context to infer terrain shape instead of guessing from color alone.

Channels 1–3
Minimap RGB
Rendered terrain appearance from the client.
Channels 4–6
Normal Map RGB
Per-pixel slope direction and surface orientation.
Channel 7
WDL Height Prior
Low-resolution world-height scaffold from WDL.
Channel 8
Height Min Hint
Per-tile lower elevation bound.
Channel 9
Height Max Hint
Per-tile upper elevation bound.
Channel 10
Liquid Mask
Where liquid covers the terrain surface.
Channel 11
Liquid Height
Liquid-surface elevation in masked regions.
Channel 12
Object Footprint
Where WMOs obscure terrain and imply structure.

2. Model Architecture — 5-Level U-Net + PatchGAN

The generator is a 5-level encoder-decoder with skip connections for detail retention. A PatchGAN discriminator sharpens local structure during training.

3. Training Signals — 9-Component Loss Function

Nine loss terms balance absolute height accuracy, slope and edge fidelity, curvature, structure, frequency detail, and adversarial sharpness.

L1 Global Height
Weight: 0.08
Per-pixel absolute error on the full-range global heightmap channel. Drives overall elevation accuracy.
L1 Local Height
Weight: 0.14
Per-pixel absolute error on the locally-normalized heightmap. Emphasizes within-tile detail.
Bounds MSE
Weight: 0.04
Mean squared error on the 4-value height bounds prediction (min, max, global min, global max).
Gradient L1
Weight: 0.10
First-order spatial derivatives (dx, dy). Penalizes incorrect terrain slopes — hillsides, ramps, inclines.
Edge (Sobel)
Weight: 0.12
Sobel-filtered edge magnitude matching. Forces correct ridgeline placement and cliff boundaries.
Laplacian
Weight: 0.12
Second-order curvature (∇²). Preserves sharp terrain features — peaks, valleys, and convexity changes.
SSIM
Weight: 0.05
Structural Similarity Index. Perceptual quality metric — luminance, contrast, and structure at window scale.
FFT Frequency
Weight: 0.08
Frequency-domain magnitude matching via log-FFT. Preserves high-frequency terrain texture.
Adversarial (GAN)
Weight: 0.12
PatchGAN discriminator signal. The critic punishes blurry patches, forcing the generator to produce sharp, realistic terrain.

7. The Goal — Reconstructing Lost Terrain

In 2010, internal development map files briefly shipped in a `4.0.0.12304` Cataclysm beta PTR build. Some files were deleted before the updater was stopped, but the surviving data was preserved.

The goal is still terrain reconstruction from real game evidence, not synthetic guesses. The current model uses minimaps, normals, WDL priors, liquid cues, and object footprints to predict terrain height.

The current state is straightforward: tile-scale trusted-corpus audit landed, the next audited full run is live, and the next deeper curation step is to identify repeated `16×16` patch and patch-group imprints left by the original WoWEdit 3D brush workflow.

The strongest completed checkpoint is still the earlier `0.0493` validation-loss baseline. The audited run finished by early stopping with best validation loss `0.1256` and final epoch `train 0.1917 / val 0.1594`. Brush-pattern discovery is a separate data problem and likely needs its own model.

This document describes the architecture and the current audited-training state. It does not claim final terrain-restoration closure.
