# Quick Verification

1. Load a world with LIT/DBC fog and open Tools > Quick.
2. Confirm the visible FogEnd matches the active lighting state; set a short valid FogEnd and verify distant terrain is clipped just past fog.
3. Use **Open detailed LIT lighting** to inspect the same source/sample.
4. Hover an isolated object: one exact card appears. Hover a dense overlapping brush: no exact card appears; left-click still inspects.
