## Why the index returns the same skin

`FindSkinInFileList` scores each `.skin` file and returns the first file (list order) with the highest
score, or null if no score is positive. A positive score needs the base name to start with the model name
(`+50`; the `00` bonuses imply it) or the directory to equal the model's directory (`+100`). The index's
candidates are: files whose ASCII-upper-cased first 3 (or 8, for model names of 8+ characters) base-name
characters equal the model name's; every file with a non-ASCII character in that prefix; every file in the
model's directory (`OrdinalIgnoreCase` map, same comparison). That set contains every positive-scoring file;
they are scored with the same function in ascending list index. Short or non-ASCII model names, a list
instance seen for the first time, or a list whose count changed use the original scan.
