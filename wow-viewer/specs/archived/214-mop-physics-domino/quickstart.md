# Quickstart: Physics Phase 0

1. Connect to the 5.0.1 Ghidra project in read-only mode. Do not create symbols, comments, data types,
   or labels.
2. Start at the assertion handler and enumerate callers only to attribute source header/line and locate
   the WoW adapter boundary. Record addresses in the evidence contract.
3. Trace the adapter to a model-sidecar discovery path and acquire a real 5.0.1 candidate through
   configured client data. Record build fingerprint and hashes.
4. Compare exact solver versions for license, deterministic step support, collision coverage, and a
   cloth route. Do not install one yet.
5. After Phase 0 evidence passes, execute Phase 1 tasks. Close the viewer before the focused test:

```powershell
dotnet test I:/parp/parp-tools/wow-viewer/tests/WowViewer.Core.Tests/WowViewer.Core.Tests.csproj -c Debug --filter "FullyQualifiedName~Physics"
```
