## 1. Overview & Problem Statement
Prior to this fix:
1. **Animation Stagnation**: On 2.0.0 (0x100 / Era100) M2 models, only eyes blinked while skeletal body animations remained frozen on frame 0.
2. **Sequence Reading & Display Names**: `M2Era100ModelReader.ReadSequences` read `startTimestamp` (+0x04) as `Duration`, causing all subsequent field offsets to shift by 4 bytes. In addition, `M2AnimationNameResolver` only mapped IDs 0..45, rendering sequences like 50 (`Loot`) as `Anim50` and 107 (`AttackThrown`) as `Anim107`.
3. **Missing Midsections & Geoset Explosion**: Standalone character models (such as `OrcFemale.m2`) had missing naked midsections/clothing because `DefaultCharacterSelectionGroups` omitted submeshes 1..8, `ApplyCharacterSelectionGroups` mis-indexed `_sectionVisibility`, and on initial model load all 51 geosets were left enabled because default customization was gated on explicit variation overrides.

---

## 2. Root Cause Analysis
- **Binary Layout of 0x100 M2Sequence (Stride 0x44 / 68 B)**:
  - `+0x00` (ushort): `animationId`
  - `+0x02` (ushort): `variationIndex`
  - `+0x04` (uint): `startTimestamp` (e.g. 3333 for Stand, 6667 for Walk)
  - `+0x08` (uint): `endTimestamp` (e.g. 5800 for Stand, 7600 for Walk)
  - `+0x0C` (float): `moveSpeed`
  - `+0x10` (uint): `flags`
  - `+0x14` (short): `frequency`
  - `+0x16` (ushort): `padding`
  - `+0x18` (uint): `replayMinimum`
  - `+0x1C` (uint): `replayMaximum`
  - `+0x20` (ushort): `blendTimeIn`
  - `+0x22` (ushort): `blendTimeOut`
  - `+0x24` (Vector3): `boundsMin`
  - `+0x30` (Vector3): `boundsMax`
  - `+0x3C` (float): `boundsRadius`
  - `+0x40` (short): `variationNext`
  - `+0x42` (ushort): `aliasNext`
- **Track Sampling Timeline**:
  In 0x100 models, track keyframe timestamps are in global timeline coordinates (`[startTimestamp, endTimestamp]`).
  `M2TrackSampler.cs` evaluated `sampleTime = timeMs % duration` (e.g. in `[0, 2467]`). Because `sampleTime < startTimestamp` (e.g. `< 3333`), it always fell before `keyFrames[0].Time`, locking bones at keyframe 0. Eye blinks use `UsesGlobalSequence` (timestamps starting at 0), which is why only eye blinks animated.
- **Geoset Filtering & Section Visibility**:
  In `ReplaceableTextureResolver.cs:DefaultCharacterSelectionGroups`, base naked torso, pelvis, limbs, hands, and feet (geosets 1..8) were omitted.
  In `M2Renderer.cs:ApplyCharacterSelectionGroups`, `_sectionVisibility` was indexed by `section.SectionIndex` instead of loop index `i`.
  In `ViewerApp.cs:RefreshStandaloneCharacterCustomizationState`, customization was only invoked if an override was >= 0, leaving default loads with all 51 geosets enabled.
