# Evidence Contract — Spec 279

1. **One question per experiment.** State alternatives before interpreting output.
2. **Raw layout is not semantics.** Cite offsets/types to the reader; cite meanings to measured data.
3. **Map-qualified references.** Preserve source file/record and target tile/record; no silent local fallback.
4. **Complete-map accounting.** Include empty files, absent addressed tiles and reader diagnostics.
5. **Controls with power.** A constructed true case must be detected; wrong-domain/offset cases must
   distinguish the tested relation. Range fits alone never close an unknown.
6. **Independent identity.** Source-object/asset claims need independently authored/geometric truth,
   not a nearest-origin or shared-field self-confirmation.
7. **Receipts.** Exact commands/status, input fingerprints, real outputs and criterion mapping are
   required before task checks. Synthetic/build output cannot satisfy visual/accuracy criteria.
8. **Nulls retained.** Rejected and inconclusive hypotheses remain in the ledger with limitations.
9. **No silent rewrites.** A new inference updates the reference and known stale routes in the same pass.
10. **Contained execution.** Outputs stay in repository/managed/operator roots. Heavy exports/GPU/
    training/client proof remain operator-owned; preserve working readers and unrelated changes.
