## Behaviour preservation (reasoning, checked in review)

- Click: the range filter now runs in the service before the clicked-chunk filter and sort, over the
  same hits in the same collection order, so the list, and the unstable `List.Sort` permutation, is
  unchanged. A limited range of NaN or < 0 gives no hits, as before (`InvalidRequest` → empty).
- Hover-by-ray still consumes the click-ranked list (collection → click ranking → hover), exactly as
  before; visibility → fall-through → range → stable `OrderBy(distance)`; liquid bodies in body order win
  only when strictly nearer and in range.
- Brush: candidates keep the WMO → MDX → liquid order and the same 0.01 cursor-distance / depth rule; the
  camera anchor is read once per evaluation instead of per candidate (same value within the frame) and
  not at all when the range is unlimited, as before.
- PM4 arbitration: ray 0.01 rule and ignore-depth; brush 0.0025 depth band then cursor distance —
  identical expressions, now in Core.
