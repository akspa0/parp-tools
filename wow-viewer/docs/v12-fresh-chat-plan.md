# V12 Texture Decomposer — Fresh Chat Execution Plan

## What We're Building

A model that decomposes a WoW minimap (256×256 RGB) into its component texture layers:
- **MCAL alpha** (256×256×4): blend weights showing how much each of 4 texture layers contributes per pixel
- **MCLY labels** (16×16): which tileset texture is used for each of 256 chunks
- **Texture residual** (256×256×3): terrain shading + object silhouettes left after textures are subtracted

The decomposed residual becomes the CLEAN input for a height model — it contains geometry
shading without texture paint.

## Why The First Attempt Failed

The initial V12 model (at `wow-viewer/scripts/train_v12.py`) takes 5 input channels:
minimap RGB + luma + Sobel gradient. It tries to predict MCAL/MCLY/residual but cannot
because the model never SEES the tileset textures. Decomposing a baked minimap without
knowing what the component textures look like is mathematically underdetermined.

## The Fix: 17-Channel Input

The model needs to see the tileset textures as reference inputs. For each tile:

```
Input channels (17 total):
  0-2:   minimap_rgb (256×256×3, uint8→float [0,1])
  3:     minimap_luma (256×256×1, derived)
  4:     minimap_gradient (256×256×1, derived)
  5-7:   tileset_layer0_rgb (256×256×3, sampled from the BLP for chunk's layer 0)
  8-10:  tileset_layer1_rgb (same for layer 1)
  11-13: tileset_layer2_rgb (same for layer 2)
  14-16: tileset_layer3_rgb (same for layer 3)
```

For each chunk (16×16 grid), we know which tileset texture is used for each layer
(via MCLY ground truth). We tile that texture across the chunk's 16×16 pixel area.
If a layer is inactive (no texture), the channel is zero.

At training time, we use GROUND TRUTH MCLY to determine which tilesets to sample.
At inference time, the model predicts MCLY first, then uses that to sample tilesets
for a second MCAL prediction pass.

## Model Architecture

- **Backbone:** ConvNeXt V2 Nano from `timm` (15.6M params)
  - Stem modified for 17-channel input (default is 3)
  - First 3 input channels initialized from ImageNet weights, channels 4-16 zero-initialized
  - Stage channels: [80, 160, 320, 640]
  - Spatial progression: 256→64→64→32→16→8

- **Decoder:** U-Net with skip connections from all 4 ConvNeXt stages
  - DecoderBlock: ConvTranspose2d(2×) → concat skip → Conv→LN→GELU→Conv→LN→GELU
  - Final: Conv→LN→GELU → F.interpolate(256×256)

- **Heads (from 64ch @ 256×256):**
  - `mcal_head`: Conv3→GELU→Conv1→sigmoid → F.interpolate(256×256) → 4ch
  - `residual_head`: Conv3→GELU→Conv1→sigmoid → F.interpolate(256×256) → 3ch
  - `mcly_head`: Conv1→GELU→Conv3 → F.interpolate(16×16) → N-class (vocabulary-dependent)

## Loss

```
L_total = 5.0 × L_mcal_l1  +  0.2 × L_mcly_ce  +  0.5 × L_residual_l1
```

MCAL gets 5× weight because it's sparse — only ~22% of pixels have non-zero alpha.
All losses are sample-masked: tiles without MCAL/MCLY/residual data don't contribute.

## Training

- **Optimizer:** AdamW, lr=2e-4, weight_decay=0.05
- **LR schedule:** 5-epoch linear warmup + cosine decay, floor at 1%
- **Batch size:** 16 (fits 8GB VRAM with 17M params)
- **Mixed precision:** AMP (GradScaler)
- **Samples:** 2000 curated from manifest, 12% validation split
- **Epochs:** 200
- **Augmentation:** random horizontal/vertical flips
- **Speed:** ~30ms per batch, ~2 hours for 200 epochs

## Success Criteria

- MCAL predictions show visible alpha patterns, not near-zero everywhere
- MapTexture composited from predicted MCAL+MCLY visually resembles the real minimap minus objects
- Residual (real - MapTexture) contains geometry shading and silhouettes, not texture colors
- Best val loss < 0.05 (current best is 0.066 with the 5ch model that can't decompose)

## After V12 Works

1. V12 decomposes minimaps → MapTextures + residuals
2. A separate height model trains on residuals alone (clean geometry signal)
3. Full pipeline: minimap → V12 → (MapTexture + residual) → height model → OBJ mesh
4. The height model sees pure terrain shading without the texture paint confusing it

```python
import torch, numpy as np

ckpt = torch.load('runs/v12_prod3/best.pt')

m.load_state_dict(ckpt['model']); m.eval(); m = m.to('cuda')

shard = 'output/tmp/v11_cache/shards/3_3_5_12340__azeroth/Azeroth_33_43.npz'

# Save MCAL layers

for l in range(4):
    Image.fromarray((mcal[:,:,l]*255).clip(0,255).astype(np.uint8)).save(f'mcal_{l}.png')

# MCAL should show visible terrain features, not near-zero everywhere
print('MCAL max per layer:', [mcal[:,:,l].max() for l in range(4)])
# Expect: something like [0.5, 0.3, 0.1, 0.0] — terrains have 1-2 dominant layers
```
