# V11.2 Terrain Model — Complete Architecture

## Goal

Regenerate **entire maps** from nothing but minimap tiles. The input at inference is a grid of 256×256 minimap PNGs. The output is a seamless 257×257 heightmap per tile, with edges matching across all tile boundaries.

No ADTs. No auxiliary signals. Just minimaps.

## Why V11.1 Failed

The single-tile architecture with per-channel dropout cannot work because:
1. The model never saw a tile with 21/26 channels zeroed during training
2. The model had no awareness of adjacent tiles — each tile was predicted in isolation
3. Edge discontinuities were never penalized during training

V11.1 was a tile predictor. We need a **map predictor**.

## Architecture

### Dual-Path Encoder (from minimap to shared geometry features)

```
                    ┌──────────────────┐
minimap (3ch) ─────→│ MinimapEncoder   │────→ 96ch @ 64×64 ──┐
                    │ (ConvNeXt Nano)  │                       │
                    └──────────────────┘                       │
                                                              ├─→ Shared ConvNeXt Stages ──→ Decoder
aux signals (23ch)  ┌──────────────────┐                       │    (96→192→384→768 channels)
(optional)    ─────→│ Full Stem        │────→ 96ch @ 64×64 ──┘
                    │ (7×7 stride-2 ×2)│
                    └──────────────────┘
```

**Training split:** 60% of batches use minimap path. 40% use full path.
**Inference:** Always minimap path. Aux signals are zero-filled and unused.

### Shared Decoder

Same U-Net decoder as V11 — ConvNeXt refinement blocks at multiple scales.
The decoder is shared between both paths, so it learns to produce good output
regardless of which encoder fed it.

### Task Heads

| Head | Output | Trained on |
|------|--------|-----------|
| height_17/65/257 | Per-tile heightmap | Both paths always |
| mcal_alpha | Texture blend weights | Full-path batches only (40%) |
| mcly_labels | Texture class per chunk | Full-path batches only (40%) |
| hole_mask | Hole locations | Full-path batches only (40%) |

## Edge Consistency: Context-Aware Training

### Problem

Tiles are predicted in isolation. Adjacent tiles at inference don't know about each other.
The seams between tiles are random — the model has no reason to make them match.

### Solution: Multi-Tile Batches

During training, each batch contains **adjacent tile pairs** instead of random tiles.
The loss includes a seam penalty that forces edge heights to match.

```
Batch composition:
  For each sample in batch:
    1. Pick a random tile (center)
    2. Include one neighbor tile (right OR bottom)
    3. Compute heights for both tiles
    4. Penalize mismatch at shared edge
```

### Seam Loss

For a batch with tiles at (x,y) and (x+1,y):
```
shared_edge_pred = center_tile[:, -1]    # rightmost column of center
shared_edge_targ = center_gt[:, -1]     # rightmost column of center GT
neighbor_edge_pred = neighbor_tile[:, 0]  # leftmost column of neighbor
neighbor_edge_targ = neighbor_gt[:, 0]   # leftmost column of neighbor GT

seam_loss = L1(shared_edge_pred, neighbor_edge_pred)  # tiles match each other
           + L1(shared_edge_pred, shared_edge_targ)   # each tile matches ground truth
           + L1(neighbor_edge_pred, neighbor_edge_targ)
```

This is applied to both horizontal and vertical edges.
Weight: 0.5× of the per-tile height loss.

### Four-Corner Consistency

At the intersection of 4 tiles, the corner pixel should be identical across all 4.
```
corner_loss = L1(corner_tl, corner_tr) + L1(corner_tl, corner_bl) + L1(corner_tl, corner_br)
```

## Context Window: Inference-Time Adjacency

At inference, we don't predict one tile at a time. We process a 3×3 window:

```
Input: 3×3 minimap grid → model sees center tile + 8 neighbors
Output: center tile's heightmap (edges informed by neighbors)
```

The model gets a 3×3×3 = 27-channel minimap input.
It predicts the CENTER tile's heightmap.
The edge tiles provide context — the model can "see" what terrain continues into adjacent tiles.

**Training:** The 3×3 window is constructed from the cache — tiles at (cx±1, cy±1).
For tiles at map edges, the missing minimap channels are zero-filled and the model
learns that "missing neighbor = map edge, predict accordingly."

### Implementation

- Input shape: [B, 27, 256, 256] (9 minimaps × 3 channels)
- Encoder stem adjusted from 26→27 channels
- Decoder unchanged — still produces single-tile output
- Only the center tile's height targets are used for loss

## Training Data: Tile Pairing

We need to build training batches where adjacent tiles are paired.

### DataLoader Modification

Instead of random sampling, the DataLoader:
1. Builds a grid of all available tiles by (X, Y)
2. For each sample, picks a center tile and ONE neighbor (right or bottom, alternating)
3. Returns the pair: `(center_input, center_targets, neighbor_input, neighbor_targets)`

The batch size doubles the memory (each sample has 2 tiles instead of 1).
Mitigated by using gradient accumulation.

### Seam Stitching During Training

The seam loss is applied on-the-fly during training. No pre-processing needed.
The model learns to predict consistent edges because the loss directly penalizes mismatches.

## Map-Level Inference Pipeline

```
For each map:
  1. Load all minimap PNGs for the map
  2. Build a grid: (x,y) → minimap array
  3. For each tile (x,y) that needs prediction:
     a. Gather 3×3 window of minimaps around (x,y)
     b. Feed to model → heightmap for (x,y)
     c. Store result
  4. Post-process: stitch edge heights between adjacent tiles
     (average shared columns/rows, average shared corners)
  5. Export as OBJ mesh or ADT files
```

The post-processing step is the same edge stitching we already implemented in
`infer_v11.py` — just average shared edges between adjacent tiles. With the
seam-aware training, the post-processing is minimal (predictions are already close).

| Detail | 5-60 | 60% | Frequency ramp: detail-first |

| Polish | 300+ | 60% | LR floor, detail pulses continue |

## Success Criteria

1. **Single-tile MAE** < 10m on held-out tiles (same as V11.1)
2. **Seam discontinuity** < 2m between adjacent tile edges (new metric)
3. **Visual continuity** — rendered map has no visible grid lines between tiles
4. **Minimap-only inference** works on 100% of tiles (guaranteed by dual-path)
5. **Edge-of-map handling** — tiles at map boundaries predict reasonable terrain (not collapsed)
