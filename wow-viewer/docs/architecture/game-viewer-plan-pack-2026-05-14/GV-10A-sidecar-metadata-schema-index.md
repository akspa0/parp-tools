# GV-10A Sidecar Metadata Schema Index

## Intent

Define the schema-index seam for forward-native per-object metadata files, including Museums object sidecars.

## Scope

- metadata document identity
- schema version tags
- object-level field inventory
- texture/material reference fields
- extension field rules

## Outputs

- `SidecarMetadataSchemaIndex`
- schema version naming rules
- strict vs extensible field policy

## Dependencies

- GV-00
- GV-04A

## Proof

- one GLB object and its metadata sidecar can be described with explicit schema identity

## Non-Goals

- no metadata editor UI
