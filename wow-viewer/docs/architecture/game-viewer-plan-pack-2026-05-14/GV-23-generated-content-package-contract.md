# GV-23 Generated Content Package Contract

## Intent

Define how future model-generated assets and worlds enter the engine without private-project assumptions.

## Scope

- package manifest
- asset payload references
- provenance fields
- compatibility/profile hints
- validation hooks

## Outputs

- `GeneratedContentPackage`
- content-package validator contract
- import/export relation to GV-11 and GV-12

## Dependencies

- GV-11, GV-12, GV-13

## Proof

- one synthetic package can be described without tying the repo to the user's private dataset platform

## Non-Goals

- no runtime generation engine
