# GV-21 Game Manager Workspace Shell

## Intent

Define the first workspace in the app shell: the place where roots, profiles, and capabilities live.

## Scope

- root list
- active root switcher
- profile summary
- capability summary
- launch points into import/export and preview workspaces

## Outputs

- workspace layout contract
- empty/loading/error states
- action routing rules

## Dependencies

- GV-07, GV-08

## Proof

- the shell can start in Game Manager and route the operator into other workflows from there

## Non-Goals

- no full asset browser yet
