# Plans Overview

This page redirects implementation routing to the live status index. It intentionally does not
duplicate task counts or historical lane summaries.

Start with [specs/STATUS.md](/I:/parp/parp-tools/wow-viewer/specs/STATUS.md), then open the owning
spec's `spec.md`, `plan.md`, and `tasks.md`. Older plans remain available for evidence when a live
spec links them; they are not default handoff context.
