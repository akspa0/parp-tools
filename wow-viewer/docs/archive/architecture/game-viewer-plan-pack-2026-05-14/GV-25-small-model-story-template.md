# GV-25 Small Model Story Template

## Intent

Standardize the shape of a micro-plan so a smaller model can execute it without re-deriving the story.

## Scope

- required headings
- bounded task wording
- explicit touched surfaces
- explicit stop conditions
- proof wording

## Required Story Fields

1. intent
2. scope
3. touched surfaces
4. inputs and assumptions
5. outputs
6. dependencies
7. proof
8. stop conditions
9. non-goals

## Outputs

- story template
- naming rules for future micro-plans
- checklist for whether a plan is small enough for a mini model

## Dependencies

- README of the plan pack

## Proof

- future plans can be audited against this template for small-model suitability

## Non-Goals

- no implementation code
