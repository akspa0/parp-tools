# GV-12A Forward Native Export Package

## Intent

Define the simplest export surface for forward-native content packages, with Museums as the first target profile.

## Scope

- GLB payload export
- texture copy/reference rules
- sidecar metadata export
- package manifest output

## Outputs

- `ForwardNativeExportPackage`
- export folder layout contract
- overwrite/provenance rules

## Dependencies

- GV-10A
- GV-12

## Proof

- one normalized asset can be exported back out as a forward-native package with explicit metadata

## Non-Goals

- no final game-runtime bundle format
