## 3. Editor Data I/O GLB Exports
- Fixed inert "Export GLB Scene" and "Export GLB Collision Mesh" buttons when viewing terrain maps by hooking `MapGlbExporter.ExportTile` for the current camera tile `(curTx, curTy)`.
- Added M2 doodad model support in `MapGlbExporter.TryLoadMdxMesh` using `M2ToMdxConverter` so M2 doodads export into GLB tile scenes without throwing exceptions.
- Added loose `.m2` model GLB export support in `ViewerApp.cs`.

---

## 4. Cartography Phase Alignment & Donor Tile Offsets
- In `PhaseChunkMerger.cs`, guarded chunk world position copying with a co-location distance check, preventing donor coordinates from displacing chunks miles away.
- In `StandardTerrainAdapter.cs` and `AlphaTerrainAdapter.cs`, re-homed donor chunks onto the target slot `(tileX, tileY)` and computed exact donor-to-target tile deltas `-(tileX - source.SourceTileX) * tileSpan` + `(cellDx, cellDy)` for both chunks and doodad/WMO placements.
- Wrapped `LoadMapTile` with `try/finally` tracking `_currentLoadingMapName`, gating `MddfPlacements.Add` and `ModfPlacements.Add` so donor map placements do not pollute the base adapter's placement list.

---

## 5. Console Suppression & Startup Resilience
- Switched Windows executable output type from `Exe` to `WinExe` in `WoWViewer.csproj` to suppress the unwanted background command prompt window.
- Registered global unhandled exception and unobserved task handlers writing crash logs to `crash.log` and `%LOCALAPPDATA%\WoWViewer\crash.log`.
- Updated listfile discovery to return cached paths immediately, run downloads in the background, or limit synchronous startup wait to 2.5s before gracefully falling back.
