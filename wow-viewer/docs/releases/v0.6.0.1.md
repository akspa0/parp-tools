# parp-tools WoW Viewer v0.6.0.1

Corrective build of the v0.6.0 line. Bring your own game data; no client files are included.

## Platform downloads

- Each platform now has two separate self-contained downloads: a viewer ZIP and a CLI-tools ZIP. The CLI
  archive contains all nine compiled command-line apphosts in a shared output directory:
  Inspector, converter, harvest, capture, validation-capture, mask validation, WDL read, WMO/minimap probe,
  and V22 enrichment. Each apphost has its own project DLL/deps/runtimeconfig; common libraries, DBDs,
  and listfiles are stored once in the shared tools output instead of nine copied runtime trees.
- The CLI-tools ZIP also includes the canonical tool map/examples (`tools/README.md`) and helper scripts;
  the viewer ZIP contains the desktop viewer and release notes without the tool runtimes.

## Fixes

- Terrain ground-effect doodads now carry interpolated MCCV color and MCSH shadow attenuation through to
  their rendered model tint, while preserving the existing directional/ambient material lighting.
- Taxi mount lookup on 1.60.1 resolves both FileDataID-backed names and legacy model paths.
- The release build workflow publishes and verifies every `.csproj` below `wow-viewer/tools/` for Windows
  x64, Linux x64, macOS arm64, and macOS x64; each RID has a separate viewer ZIP and CLI-tools ZIP.

The viewer continues to support clients 0.5.3–0.11 completely, 0.12–5.x partially, and WoW: Forever
1.60.1 as documented in the v0.6.0 release notes.
