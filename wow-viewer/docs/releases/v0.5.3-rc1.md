# parp-tools WoW Viewer v0.5.3-rc1

Release candidate for **v0.5.3** — the first properly-versioned build since v0.5.2.1, and the
largest gap between releases so far: **160 commits** of new capability since the last tag. This
page summarizes what changed between `v0.5.2.1` and this build. Runtime/visual acceptance for the
headline items remains operator-owned per the workspace validation rules.

## 5.0.1 era support (Mists of Pandaria beta groundwork)

The viewer's data pipeline now has the foundations for the **5.0.1.15464** client era:

- **Client-era admission policy** — a solver-independent era/admission policy for physics and
  format handling, so 5.0.1-era data is admitted or rejected by explicit rules instead of
  accidental reader tolerance (Spec 214).
- **`.phys` sidecar reader** — fail-closed, diagnostic `.phys` decoding (Spec 214, T013–T018),
  with the format decoded against real client data and a physics solver selected (Jitter2).
- **Ghidra-verified decode evidence** — read-only reverse-engineering passes against the
  preserved source-path strings in `Wow.exe` (5.0.1.15464, 38,405 functions) anchoring the
  atmosphere, physics, and weather systems (Specs 214–217), plus creature staging (Spec 218) and
  the effect-driven lighting correction (Spec 216).

## PM4: from hex guessing to measured semantics

The largest single body of work. Every PM4 record field was characterized by behavior, with
claims withdrawn when measurement disproved them:

- **Field semantics settled**: `MSUR._0x1C` is placement Z (packed Vector3 reading eliminated);
  `MSLK.LinkId` is a reversed tile address; `MSUR._0x00` is a surface class with `0x03`
  independently marking the M2 population; the `_0x1C == 0` bucket is M2 doodad collision, not a
  "tile remainder"; `CK24 == 0` is the tile remainder, not object id zero; MSCN is a shared node
  network; MSHD/MPRL/MPRR spans narrowed with per-stream extents tooling (`mshd-dump`).
- **Placement recovery**: object placements are regenerated from PM4 geometry for tiles whose
  own placement data is gone, drawn in the viewer, and written back to ADTs.
- **PM4-guided reconciliation** (Spec 176): real preview, residual-derived confidences, bulk
  accept, hardened apply, a Reconcile tab, and staged-save integration for authored placement
  edits — plus museum placement repair and PM4-guided object transfer.
- **wowdev wiki drafts** recording provenance and the field-by-field state-of-knowledge ledger.

## Terrain restoration & archaeology tooling

- **Temporal stratigraphy analysis, overhead chunk transposition, and WDL magnetization engines**
  for terrain restoration.
- **Terrain template brush library, layer allocator, editor plugin, and map generator** (Spec 192).
- **Archaeology workspace** and an ML training workflow interface with process monitoring.
- **Phase map overlays**: multi-layer phase map overlay system with phase layer management in
  `TerrainManager` and minimap rendering.
- **Liquid work**: MH2O liquid vertex format chain, and a liquid convergence analyzer that
  diagnoses shoreline waterline culling.
- **Terrain shading measurement** support for per-vertex lighting inputs.

## Rosetta: procedural map generation (Spec 190)

- Deterministic PM4 lookup engine, companion ADT synthesizer with provenance, and the
  `RosettaTilesetGenerator` for chunk-aligned, deterministic map asset placement and ADT
  serialization.
- First-class **Alpha 0.5.3 `Map.dbc` / `AreaTable.dbc`**, WDL meshes, TRS mapping, MDX/WMO
  splitting, and +20Z bounding-box placement.
- Minimap generation with BLP2 encoding for calibration maps; texture painting and terrain
  sculpting with DBC patching for new map creation.

## ADT/WDT converter correctness

- Real monolithic LK ADT writing with corrected chunk sizes; chunk padding removed with a real
  verification command.
- Alpha WDT conversion no longer loses area ids, chunk flags, or doodads.
- **PTCH/BSDIFF ADT patch artifacts are reconstructed before parsing** (Spec 197); ADT chunk
  collection and sparse-MCIN texture reading now have test coverage.
- Terrain chunk parsing refactored to adhere to native rules; MODF fields past flags are read.

## Alpha demo restoration

- **WTF command inspection** (Specs 158/159): a WTF sweeper run for real against 0.5.3.3368 and
  2.0.0.5610, archive-packed WTF content confirmed real, candidate probing, and a WTF explorer

- **Skybox rendering** (Spec 160) with automated skybox validation.

## Selection, picking & editor platform

- **WMO interior ray picking, doodad selection, and ghost transparent wireframes** (Spec 211).
- **Oriented selection boxes** for MDX and WMO doodads, separate from culling bounds, with a
  1.5-yard minimum for tiny objects and 3D aids.
- **Unified object inspector** consolidating modular terrain/model analysis; editor host
  framework for placement, terrain-template, and chunk-manipulation authoring; terrain
  inspection features; multi-map, multi-tile **cartography composition workbench** (Spec 222)
  with footprint drag and cache versioning.
- **Archaeology workspace** UI; in-app cross-platform ImGui path picker.

## Renderer performance & correctness

- **GPU instancing completed** for world models (Specs 201/202) and **object draw-call reduction**
  (Spec 207), with submission metrics split per route.
- WMO group admission rules named and enforced (Spec 154 lane); RouteBlocked detection and a WMO
  group-file misread fix (Spec 155); M2 reader repair between MDLX and MD20 0x108 (Spec 154).
- WMO doodad inventory and cross-build asset chronology sweeping (Spec 155).

## This rc's own fixes

- **Version plumbing repaired** (the reason this is rc1): `eng/Version.props` was never imported
  by any project (a bare relative `Exists()` resolves against the *project* directory), a
  shadowing `Directory.Build.props` in the viewer source directory blocked the repo-level file,
  and both viewer csprojs hardcoded `0.5.2.2`. All fixed — one version source
  ([eng/Version.props](../../eng/Version.props)), title/About derived from the assembly.
- **Wireframe modes fixed**: terrain and M2/MDX wireframe passes re-used the textured fill
  shader, making terrain lines invisible and object lines collapse into orange alpha-cutout
  fragments. All wireframe passes now draw flat-colored untextured lines.
- **Editor toolbar**: `Anim` toggle for world doodad animations (now defaulting to on) and a
  doodad-set combo for the hovered WMO.
