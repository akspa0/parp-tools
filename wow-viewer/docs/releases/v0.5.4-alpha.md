# parp-tools WoW Viewer v0.5.4-alpha

**Alpha pre-release.** This build opens modern CASC game installs, starting with **WoW: Forever**: the
`wow_classic_beta` product, build **1.60.1.69876** (a 12.0-based client). It reads that client's
FileDataID-era maps, models and database tables. It also adds a first reader and renderer for **DAT v26**,
the raw terrain project files that shipped in the same build.

Expect rough edges. Everything below was tested against a real `wow_classic_beta` install; items marked
*not yet* are known gaps.

---

## 1. Opening a CASC install (local, with optional CDN fill)

- **File → Open CASC Install (local)...**: pick the folder that contains `.build.info`. Every product
  listed there is opened. Reads try the newest version first and fall back to older products when a file
  is missing locally.
- **File → Open CASC Install (local + CDN fill)...**: the same, but files the install lists without
  having the data on disk are downloaded from Blizzard's CDN for the same build and cached under
  `output\cache\casc`. In the tested `wow_classic_beta` install most textures were not on disk, so use
  this option to see textures.
- If the launcher has rewritten `.build.info` with a CDN configuration that is not on disk yet, the
  missing manifests for that build are fetched from the CDN automatically. This is logged.
- Built on [TACTSharp](https://github.com/wowdev/TACTSharp) (vendored as a submodule). File names come
  from the [community listfile](https://github.com/wowdev/wow-listfile); database layouts come from
  [WoWDBDefs](https://github.com/wowdev/WoWDBDefs), which includes 1.60.1.69876.

## 2. FileDataID-era assets

- **Maps**: the tile files come from the WDT's `MAID` table. Terrain texture names come from `MDID`
  (the files have no `MTEX`). Model placements flagged `0x40` (M2) and `0x8` (WMO) are resolved by
  FileDataID. Map list, area names, lights and liquid types come from the build's own DB2 tables.
- **Terrain textures render at full resolution**: each chunk's texture layers are blended with their
  alpha maps, using the tileset textures themselves rather than a baked map texture.
- **M2 models**: chunked (`MD21`) models load on the native render path, with skins from `SFID` and
  textures from `TXID`.
- **WMO buildings**: roots without `MOTX`/`MODN`, groups from `GFID`, material textures and doodads by
  FileDataID. Newer root and group chunk layouts are accepted (`MGI2`, `MOPE`, `MOLV`, `MDDI`, `MNLD`,
  `MFED`, `MAVG`, `MAVD`, `MOGX`, `MPY2`, `MOVX`). A WMO that still fails to parse is skipped with a
  log line instead of crashing the viewer.

Measured on the `development` map (Map 451): all 82 tiles load. All 72 placed WMOs parse with geometry.
540 of 541 placed M2 models build with draw sections, and the remaining one builds with none.

## 3. Loading speed

- CASC reads run in parallel. Concurrent reads were verified byte-identical to sequential reads
  (1,487 files, 12 threads).
- A background prefetch pool loads the files a model needs next (skin, textures, WMO groups, doodads)
  and the textures of each terrain tile as soon as it is parsed.
- Measured: first-time download of the 460 WMO textures on `development` went from 87.7 s (one at a
  time) to 5.3 s (parallel). Once cached they read in about 1 s.
- *Not yet*: texture decoding (about 2.5 s on one thread for those 460) and GPU upload of
  full-resolution textures remain the main warm-load cost.

## 4. DAT v26 terrain (new format)

- **File → Open DAT v26 Terrain Folder...**: opens a folder of DAT v26 files (any file names) and
  places each tile by its `ALOC` chunk. Heights, normals, texture layers and alpha maps render.
- **File → DAT v26 Height Scale**: DAT heights appear to be stored in inches, so the default divisor is 36.
  Evidence: −18,559.47 ÷ 36 = −515.54, matching the shipped ocean floor. Other options are 1×, ÷12 and ÷100.
- *Not yet*: object placements (`ACDO`), vertex colours (`ACVT`) and shadows (`ASHD`). The horizontal scale
  relative to shipped ADTs is not established yet.
- Format write-up: [`docs/architecture/adt-v26-format.md`](../architecture/adt-v26-format.md). A wowdev.wiki
  draft is in [`docs/wowdev-wiki/dat-v26.wiki`](../wowdev-wiki/dat-v26.wiki).

## 5. CLI (`WowViewer.Tool.Inspect`)

New `casc` commands: `products`, `read`, `exists`, `wmo`, `m2`, `db2`, `map-survey`, `adt-heights`,
`bench`. New `adt-ahdr check` command. See [`docs/CLI-TOOLS.md`](../CLI-TOOLS.md#casc-installs-casc).

## Known limitations

- Chunks render at most 4 texture layers (every chunk measured on `development` has at most 4). Layers
  whose `MDID` entry is 0 in the shipped data (396 layer references on `development`) have no texture.
- Height-based texture blending (`MHID`) is not used by the terrain shader yet.
- The Azeroth WDT's `MAI2` chunk is not interpreted.
- `GFID` WMO group loading is wired into world loading. Screenshot, GLB export and the standalone WMO
  viewer still find groups by name.
- Remote-only CDN browsing without a local install is not in this build.
